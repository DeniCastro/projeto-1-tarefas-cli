# Projeto 1: Tarefas CLI

> Um programa interpretador de linha de comando será responsável por processar o texto inserido e executar uma ação.

## O que é

Uma frase sobre o problema que o projeto resolve.

## Como instalar

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
```

## Como usar

```bash
python -m tarefas adicionar "Estudar pytest"
python -m tarefas listar
python -m tarefas concluir 1
python -m tarefas remover 1
```

(Ajuste conforme os comandos que você implementar.)

## Como rodar os testes

```bash
python -m pytest -v
```
